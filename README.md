# Tempest Studio

Run with Node.js 20 or newer:

```bash
npm start
```

Then open http://127.0.0.1:4120.

Optional environment variables:

- `SC_API_PORT`: local port, defaults to `4120`.
- `SC_DB_PATH`: project database path relative to this folder, defaults to `projects/db.json`.
- `TEMPEST_STATIC_DIR`: override the frontend build directory.
